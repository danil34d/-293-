# Документация по проекту

Актуальные файлы:
- `00-ПЛАН-ЗАПУСКА.md` - как запускать проект на Windows и Linux, что проверять после старта.
- `01-КАРТА-ПРОЕКТА.md` - структура, модули, API и хранилище данных.
- `02-ШПАРГАЛКИ.md` - быстрые команды и диагностика.
- `03-ЖУРНАЛ-РАБОТ.md` - журнал выполненных технических работ и исправлений.
- `04-СТАТУС-СИСТЕМЫ.md` - текущий статус разделов, API, риски и регламент рутинной проверки.
- `05-ПЛАН-УЛУЧШЕНИЙ.md` - структурированный план улучшений, карта функционала и 4 направления анализа.
- `06-ЖУРНАЛ-БД-ВЗАИМОДЕЙСТВИЯ.md` - карта данных (`data/*`), связи сущностей, эффекты write-операций и риски гонок.
- `07-ВЕБ-TG-ЖУРНАЛ.md` - единая картина работы веба и Telegram-бота: архитектура, маршруты, бизнес-потоки и ограничения.
- `08-ГРАФИК-СМЕН-И-ПЛАНИРОВАНИЕ.md` - глубокое описание смен: `/schedule`, `/schedule/planning`, авто-fill, заявки, Telegram-график и уведомления.
- `09-ПОГОДА-И-ПАТТЕРНЫ.md` - рекомендации по требованиям на месяц (погода/пики), журнал паттернов и файлы `data/_meta/pattern-journal/*`.
- Telegram Bot (MVP) описан в:
  - `02-ШПАРГАЛКИ.md` (настройка ENV, команды, служебные API),
  - `03-ЖУРНАЛ-РАБОТ.md` (что внедрено технически),
  - `04-СТАТУС-СИСТЕМЫ.md` (текущий статус эксплуатации).

Служебные папки:
- `src/` - исходники приложения.
- `backend-go/` - Go backend.
- `data/` - рабочие данные проекта.
- `telegram-bot/` - отдельный worker Telegram (бот сотрудника), локальный `telegram-bot/.env.local`, журналы.

ENV-файлы:
- `.env.local` (корень проекта) - общие настройки приложения: backend, AI и `TELEGRAM_BOT_SECRET` (для internal API Telegram).
- `telegram-bot/.env.local` - только настройки Telegram-бота (токен, секрет, интервалы, привязки).

Скрипты Windows:
- `START.bat` / `START.ps1` - запуск frontend + backend + telegram worker, с автоматическим выбором свободного порта из диапазонов `3000..3005` и `8080..8085`.
- `STOP.bat` / `STOP.ps1` - остановка только процессов этого проекта; чужие сервисы на тех же портах не убиваются.
- `scripts/health-check.ps1` - рутинная проверка страниц и API.
- `scripts/cleanup-safe.ps1` - безопасная очистка только генерируемых артефактов.
- `scripts/rebuild-safe.ps1` - безопасная пересборка: stop -> cleanup -> install -> typecheck -> build -> bot dry-check.
- `scripts/migrations/json-v2/*` - миграция файловой БД в формат `json-v2` (dry-run/apply + отчеты).
