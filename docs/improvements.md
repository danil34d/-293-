# Улучшения приложения ZORIN — Автомойка

Анализ всех разделов с практичными предложениями для сотрудников и менеджеров.

---

## ПРИОРИТЕТ 1 — Быстрые улучшения (высокая отдача, небольшой объём работы)

### Дашборд
- **Сравнение с прошлым периодом** — рядом с каждой метрикой (выручка, моек, расходы) показывать % изменения по сравнению с предыдущим аналогичным периодом (неделя к неделе, месяц к месяцу). Менеджер сразу видит тренд.
- **Быстрые пресеты дат** — кнопки «Сегодня», «Эта неделя», «Этот месяц», «Квартал» вместо ручного выбора дат.
- **Экспорт дашборда в PDF** — менеджер может скачать отчёт и отправить владельцу.

### Рабочая станция (для сотрудников)
- **Быстрые кнопки частых услуг** — топ-3 комбинации услуг (например «Полная мойка + коврики») одной кнопкой, чтобы не выбирать каждый раз.
- **История авто** — при вводе номера сразу показывать краткую историю: последний визит, что делали, комментарии водителя. Сейчас это частично есть (последняя мойка), но можно расширить до 3-5 последних визитов.
- **Таймер мойки** — простой секундомер/таймер от момента начала мойки до завершения. Помогает отслеживать производительность.
- **Звуковое уведомление** — при успешном распознавании номера OCR, чтобы сотрудник не смотрел на экран постоянно.

### Журнал моек
- **Фильтры** — по дате, сотруднику, способу оплаты, типу клиента (розница/агрегатор/контрагент). Сейчас нет фильтрации.
- **Поиск по номеру авто** — быстрый поиск конкретной машины в журнале.
- **Итоги дня** — внизу таблицы показывать сумму: количество моек, общая выручка, разбивка по способам оплаты.

### Сотрудники
- **Статус сотрудника** — «Активен» / «В отпуске» / «Уволен» вместо удаления. Уволенные скрываются из основного списка, но их история сохраняется.
- **Поиск и фильтр** — по имени, роли, схеме зарплаты.
- **Показатели рядом с именем** — количество смен за месяц и заработок за месяц прямо в таблице.

## ПРИОРИТЕТ 2 — Средние улучшения (значительная отдача)

### Смены / График
- **Шаблоны графика** — сохранять типовой график (например: Иванов — понедельник/среда/пятница, день) и применять его на новый месяц одной кнопкой.
- **Учёт отпусков/больничных** — в карточке сотрудника отмечать даты отсутствия. Автозаполнение не ставит его в эти дни.
- **Уведомления о смене** — push/Telegram уведомление сотруднику когда его ставят на смену или когда смена меняется.
- **Drag & Drop** — перетаскивание сотрудников на ячейки календаря вместо диалоговых окон.

### Контрагенты
- **Баланс и акт сверки** — кнопка «Сформировать акт сверки» с историей всех моек и оплат. Сейчас баланс виден, но нет инструмента сверки.
- **Автоматическое напоминание** — если баланс контрагента ниже порога, уведомление менеджеру.
- **Срок действия договора** — дата окончания договора + напоминание за 30 дней до окончания.

### Агрегаторы
- **Процент комиссии** — отображать % комиссии агрегатора и чистую выручку после комиссии.
- **Статистика по агрегатору** — количество заказов, средний чек, доля в общей выручке — прямо в списке.
- **Переключение активного прайса** — кнопка «Сделать активным» рядом с каждым прайс-листом.

### Расходы
- **Категории с иконками** — визуальное разделение: аренда, химия, оборудование, хозтовары, зарплата, прочее.
- **Фильтр по категории и дате** — сейчас нет фильтрации в журнале расходов.
- **Повторяющиеся расходы** — шаблон для ежемесячных платежей (аренда, коммуналка). Автоматически добавляются 1-го числа каждого месяца.
- **Бюджет** — задать плановый бюджет по категориям. Показывать «план / факт» и процент использования.

### Склад
- **Уведомления о низком остатке** — когда запас химии опускается ниже порога (настраиваемого), показывать предупреждение на дашборде и отправлять в Telegram.
- **История списаний** — подробный лог: сколько израсходовано на каждую мойку, когда и сколько закупили.
- **Несколько видов химии** — сейчас учёт ведётся «химия вообще». Разбить на виды: шампунь, воск, чернитель, полироль и т.д. с отдельным учётом остатков по каждому.

### Прайс-лист
- **Сезонные цены** — возможность задать зимний и летний прайс с автопереключением по дате.
- **История изменений** — лог изменений цен (кто, когда, с какой на какую).

## ПРИОРИТЕТ 3 — Крупные улучшения (большой эффект, больше работы)

### Клиентская база / CRM
- **Карточка клиента** — объединить все данные по номеру авто: все визиты, общая сумма, частота посещений, любимые услуги, комментарии водителей.
- **Программа лояльности** — каждая N-ая мойка бесплатно или скидка. Отслеживать количество визитов.
- **SMS/Telegram рассылка** — если клиент не приезжал больше 30 дней, автоматическое напоминание со скидкой.

### Отчёт по зарплате
- **Периоды выплат** — настраиваемые периоды (1-15 и 16-конец месяца, или помесячно).
- **Учёт авансов и штрафов** — фиксировать выданные авансы, которые вычитаются из зарплаты.
- **Зарплатная ведомость** — формирование PDF ведомости для подписи.
- **Расчётный листок сотрудника** — сотрудник видит детальную расшифровку: за какие мойки сколько заработал, минус авансы, итого к выплате.

### Счета
- **Номерация счетов** — автоматическая нумерация (не ручная). Формат: YYYY-NNN.
- **Статусы** — «Черновик», «Отправлен», «Оплачен», «Просрочен». Цветовая маркировка.
- **Реквизиты в настройках** — сейчас реквизиты ИП захардкожены в коде. Вынести в настройки, чтобы можно было менять без разработчика.
- **Отправка по email** — из карточки счёта кнопка «Отправить на email» контрагенту.

### Розничные транзакции
- **Кассовая сверка** — итоги по наличным за смену. Сотрудник в конце смены вводит сумму из кассы, система сравнивает с расчётной.
- **Чаевые** — поле для фиксации чаевых, привязанных к сотруднику.
- **Возвраты** — механизм возврата: отменить мойку, вернуть деньги. Сейчас только удаление записи.

## ПРИОРИТЕТ 4 — Системные улучшения

### UX / Интерфейс
- **Мобильная версия** — таблицы заменить на карточки на мобильных. Рабочая станция должна быть mobile-first (сотрудники работают с телефона/планшета).
- **Тёмная тема** — для работы в ночные смены.
- **Глобальный поиск** — одна строка поиска вверху: ищет по номерам авто, именам сотрудников, контрагентам, счетам.
- **Центр уведомлений** — колокольчик с непрочитанными: новые запросы на замену смен, низкий остаток химии, просроченные счета, и т.д.

### Данные и производительность
- **Пагинация** — во всех таблицах (моек, транзакций, расходов). Сейчас загружается всё.
- **Кеширование** — данные дашборда кешировать, обновлять фоном.
- **Аудит изменений** — лог: кто что изменил, когда. Важно для финансовых данных.

### Интеграции
- **Онлайн-касса** — интеграция с ОФД для автоматической фискализации.
- **1С / Бухгалтерия** — экспорт расходов и выручки в формате 1С.
- **Google Calendar / iCal** — синхронизация графика смен с календарём сотрудника.

## Связи между разделами (что можно соединить)

1. **Дашборд ↔ Все разделы** — клик на метрику дашборда открывает соответствующий раздел с фильтром. Например: клик на «Выручка за агрегаторы» → переход в Транзакции с фильтром по агрегаторам.

2. **Рабочая станция → Журнал моек** — после завершения мойки показывать ссылку на запись в журнале.

3. **Контрагенты/Агрегаторы → Счета** — кнопка «Выставить счёт» прямо из карточки контрагента, автоматически заполняя реквизиты и список услуг за период.

4. **Смены → Зарплата** — из графика смен видеть прогноз заработка сотрудника на месяц (на основе средней выручки за смену).

5. **Склад → Расходы** — при добавлении расхода категории «Химия» автоматически увеличивать остаток на складе.

6. **Анализ клиентов → Рабочая станция** — при вводе номера авто показывать LTV клиента и предложения по допуслугам.

7. **Зарплата → Финансы сотрудника (Telegram)** — сотрудник получает расчётный листок в Telegram в день выплаты.
