# Логика Telegram-бота и меню

## 1. Назначение бота
- Бот обслуживает сотрудника автомойки в Telegram.
- Основные задачи:
  - оформлять мойку полностью в чате (`/wash`);
  - показывать личный график (подменю «График»);
  - управлять заявками и передачей смен;
  - показывать финансы с навигацией по месяцам;
  - уведомлять о сменах, заявках, мойках и финансовых операциях;
  - открывать рабочую станцию (`/employee/workstation`) в 1 клик через WebApp без ручного логина.

## 2. Базовая архитектура
- Worker: `telegram-bot/worker.mjs` (long polling).
- Данные состояния worker:
  - `data/telegram-bot/state.json`
  - `data/telegram-bot/conversations.json`
  - `data/telegram-bot/metrics-YYYY-MM-DD.json`
- Internal API:
  - `/api/telegram/internal/*` (защищены `x-telegram-bot-secret`)
- WebApp login:
  - `POST /api/telegram/internal/webapp-session/create`
  - `GET /api/telegram/webapp-login?token=...`

## 3. Структура меню (карта навигации)

### 3.1 Главное меню
Кнопки:
1. `🚗 Оформить мойку` (полная ширина — главная рабочая кнопка)
2. `🚿 Рабочая станция` | `📅 График`
3. `💰 Финансы` | `🔐 Логин/пароль`
4. `🔄 Обновить` | `❓ Помощь`

Сводка при открытии:
- Количество смен сегодня
- Общее количество заявок (+ бейдж входящих)
- Баланс за текущий месяц
- Время обновления

### 3.2 Подменю «📅 График»
Показывает сводку: сколько смен сегодня/неделя/месяц, напарники.

Кнопки:
1. `🗓 Сегодня` | `📅 Неделя` | `🧾 Месяц`
2. `📨 Заявки`
3. `➕ Запросить смену` | `🔄 Передать смену`
4. `◀️ Главное меню`

### 3.3 Подменю «💰 Финансы»
Структурированный вывод с разделами «Доходы», «Расходы», «К выплате», «Статистика».

Кнопки навигации по месяцам:
1. `◀️ Пред. месяц` | `След. месяц ▶️`
2. `◀️ Главное меню`

### 3.4 Запрос смены (мастер)
Шаги:
1. **Выбор даты** — inline-календарь на 14 дней вперёд (кнопками, без ручного ввода)
2. **Тип смены** — `☀️ День` | `🌙 Ночь` (+ кнопка отмены)
3. **Бокс** — `1️⃣ Бокс 1` | `2️⃣ Бокс 2` (+ кнопка отмены)
4. **Комментарий** — текст или кнопка `⏭ Пропустить` (+ кнопка отмены)

На каждом шаге есть `❌ Отмена` → возврат в подменю «График».

### 3.5 Просмотр графика (детальный)
Формат вывода смены:
```

📌 2026-02-25 (Вт)
   Бокс 2 | ночь | 20:00-08:00
```

### 3.7 Просмотр заявок (детальный)
Формат вывода:
```
📨 Ваши заявки
━━━━━━━━━━━━━━━━━━

   🟡 2026-02-25 (Вт) | бокс 1 | день
```

Иконки статусов: 🟡 pending, 🟢 accepted, 🔴 rejected, ⚪ cancelled

## 4. Команды сотрудника

| Команда | Что делает | Следующий экран |
|---|---|---|
| `/start` | Проверка доступа и вывод главного меню | Главное меню |
| `/menu` | Открывает главное меню | Главное меню |
| `/wash` | Запускает чатовый мастер оформления мойки | Шаг выбора команды / блокировка без смены |
| `/workstation` | Создает одноразовую WebApp-сессию | Сообщение с кнопкой WebApp |
| `/today` | График на сегодня | Детальный график |
| `/week` | График на 7 дней | Детальный график |
| `/month` | График на месяц | Детальный график |
| `/requests` | Входящие/исходящие заявки | Заявки с действиями |
| `/finance` | Финансы за текущий месяц | Финансовая сводка |
| `/credentials` | Логин/пароль сотрудника | Данные входа |
| `/help` | Справка по командам | Справка |
| `/cancel` | Отмена активного мастера | Главное меню |

| Callback | Назначение |
|---|---|
| `cmd:menu` | Главное меню (+ очистка conversation) |
| `cmd:schedule_menu` | Подменю «График» (+ очистка conversation) |
| `cmd:finance_menu` | Финансы текущего месяца |
| `cmd:wash` | Запуск мастера мойки |
| `cmd:workstation` | WebApp-ссылка |
| `cmd:help` | Справка |
| `cmd:today` / `cmd:week` / `cmd:month` | Детальный график |
| `cmd:requests` | Заявки |
| `cmd:finance` | Финансы текущего месяца |
| `cmd:credentials` | Логин/пароль |

### Финансы — навигация по месяцам
| Callback | Назначение |
|---|---|
| `fin:YYYY-MM` | Финансы за указанный месяц |

### Запрос смены (assignment)
| Callback | Назначение |
|---|---|
| `as_new` | Показать календарь выбора даты |
| `as_date:YYYY-MM-DD` | Выбрать дату из календаря |
| `as_shift:day` / `as_shift:night` | Тип смены |
| `as_box:1` / `as_box:2` | Номер бокса |
| `as_skip_comment` | Пропустить комментарий |
| `as_cancel:{id}` | Отмена своей заявки |

### Передача смены (swap)
| Callback | Назначение |
|---|---|
| `sw_new` | Начать передачу смены |
| `sw_pick_shift:{id}` | Выбрать смену |
| `sw_pick_target:{id}` | Выбрать сотрудника |
| `sw_yes:{id}` | Принять входящую заявку |
| `sw_no:{id}` | Отклонить входящую заявку |

### Мастер мойки
| Callback | Назначение |
|---|---|
| `w:*` | Все callback мастера мойки (обрабатываются в `wash-flow.mjs`) |

## 6. Сценарий "Рабочая станция" (WebApp)

### 6.1 Как открывается
1. Сотрудник нажимает `🚿 Рабочая станция` или вводит `/workstation`.
2. Worker создает одноразовую сессию через internal API.
3. Бот отправляет кнопку `🚿 Открыть рабочую станцию` (`web_app.url`).
4. Telegram открывает URL `/api/telegram/webapp-login?token=...`.
5. Сервер валидирует токен, ставит cookie `employee_auth_sim`, делает redirect на `/employee/workstation`.

Примечание для локального режима:
- если `TELEGRAM_APP_BASE_URL` использует `http://`, Telegram не примет `web_app` кнопку;
- для `localhost/127.0.0.1` бот отправляет ссылку текстом (без URL-кнопки).

### 6.2 Что доступно после открытия
Это штатная веб-станция `ZorinWorkstationConsole` без урезаний:
1. Старт/стоп смены.
2. Выбор команды.
3. Ввод/распознавание номера.
4. Определение типа клиента (розница/контрагент/агрегатор).
5. Выбор оплаты.
6. Выбор услуг, поиск, повтор визита, доп.услуги.
7. Комментарий, подтверждение, регистрация мойки.

## 7. Сценарий `/wash` (чатовый мастер)
Шаги:
1. `team`: выбор команды исполнителей (инициатор всегда в команде).
2. `vehicle_input`: ввод номера текстом или фото (OCR).
3. `payment_select`: cash, card, transfer, aggregator, counterAgentContract.
4. `aggregator_select` / `counter_agent_select`: выбор клиента.
5. `service_browse`: услуги с поиском, пагинацией, повтор прошлой.
6. `comment` -> `confirm`: финальная проверка и регистрация.

## 8. Тексты ошибок и fallback
- Нет привязки сотрудника: `Доступ к боту не выдан...`
- Internal API недоступен: `Сервис временно недоступен. Попробуйте еще раз через 10-20 секунд.`
- Ошибка callback: уведомление + предложение `/menu`.
- Ошибка WebApp-токена: redirect на `/login?error=tg_webapp_auth_failed`.

## 9. Инварианты безопасности
1. Internal API только по `x-telegram-bot-secret`.
2. WebApp-токен одноразовый.
3. У токена есть TTL (`TELEGRAM_WEBAPP_SESSION_TTL_SEC`, по умолчанию `120` сек).
4. Cookie ставится как при обычном логине (`httpOnly`, `sameSite=lax`, `secure` в production).
