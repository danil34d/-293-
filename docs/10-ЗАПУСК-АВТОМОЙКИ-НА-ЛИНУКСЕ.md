# Запуск автомойки на Линуксе

## Что сделано
- Проект на Linux хранится в `/srv/carwash/app`.
- Рабочие данные хранятся в `/srv/carwash/data`.
- На рабочем столе Linux создана папка `Проект автомойки`, которая ведет в рабочую папку проекта.
- На рабочем столе Linux создан ярлык `Запустить автомойку`, который открывает проект и при необходимости перезапускает сервисы.

## Как запускать
1. На рабочем столе Linux дважды нажмите `Запустить автомойку`.
2. Дождитесь открытия страницы входа.
3. Войдите в систему:
   - логин: `admin`
   - пароль: `admin`

## Что есть на рабочем столе
- `Проект автомойки` - папка с проектом.
- `Запустить автомойку` - запуск веб-приложения.
- `Открыть проект автомойки` - открыть проект в терминале.
- `Логи автомойки` - открыть логи сервисов.

## Если что-то не открылось
1. Нажмите `Запустить автомойку` еще раз.
2. Проверьте, что Linux загрузился полностью и сеть активна.
3. Если нужно, вручную проверьте сервисы:

```bash
systemctl status carwash-web.service
systemctl status carwash-bot.service
```

4. Проверка веба:

```bash
curl -I http://127.0.0.1:3000/login
```

## Полезные пути
- Проект: `/srv/carwash/app`
- Данные: `/srv/carwash/data`
- OCR Python: `/srv/carwash/.venv-ocr/bin/python`

## Примечание
- После перезагрузки Linux сервисы `carwash-web.service` и `carwash-bot.service` стартуют автоматически.
- OCR на этом ПК переведен на RapidOCR, потому что EasyOCR на данном процессоре работал нестабильно.

## Если на рабочем столе вопросики вместо русских названий
Откройте `Terminal` на самом Linux и выполните:

```bash
find "$HOME/Desktop" -maxdepth 1 -type l -lname '/srv/carwash/app' ! -name 'Проект автомойки' -delete
rm -rf "$HOME/Desktop/Проект автомойки"
ln -s /srv/carwash/app "$HOME/Desktop/Проект автомойки"

cat >"$HOME/Desktop/Запустить автомойку.desktop" <<'EOF'
[Desktop Entry]
Type=Application
Name=Запустить автомойку
Comment=Открыть автомойку и при необходимости перезапустить сервисы
Exec=/usr/local/bin/carwash-launch.sh
Terminal=true
Icon=system-run
Categories=Utility;
EOF

cat >"$HOME/Desktop/Открыть проект автомойки.desktop" <<'EOF'
[Desktop Entry]
Type=Application
Name=Открыть проект автомойки
Comment=Открыть папку проекта в терминале
Exec=/usr/local/bin/carwash-open-project.sh
Terminal=false
Icon=folder
Categories=Development;
EOF

cat >"$HOME/Desktop/Логи автомойки.desktop" <<'EOF'
[Desktop Entry]
Type=Application
Name=Логи автомойки
Comment=Открыть журналы сервисов автомойки
Exec=/usr/local/bin/carwash-open-logs.sh
Terminal=false
Icon=text-x-log
Categories=Utility;
EOF

chmod +x \
  "$HOME/Desktop/Запустить автомойку.desktop" \
  "$HOME/Desktop/Открыть проект автомойки.desktop" \
  "$HOME/Desktop/Логи автомойки.desktop"

for f in "$HOME/Desktop"/*.desktop; do
  [ -e "$f" ] || continue
  base="$(basename "$f")"
  if grep -q '^Exec=/usr/local/bin/carwash-launch.sh$' "$f" && [ "$base" != 'Запустить автомойку.desktop' ]; then rm -f "$f"; fi
  if grep -q '^Exec=/usr/local/bin/carwash-open-project.sh$' "$f" && [ "$base" != 'Открыть проект автомойки.desktop' ]; then rm -f "$f"; fi
  if grep -q '^Exec=/usr/local/bin/carwash-open-logs.sh$' "$f" && [ "$base" != 'Логи автомойки.desktop' ]; then rm -f "$f"; fi
done

rm -f "$HOME/Desktop/Carwash.desktop" "$HOME/Desktop/Project.desktop" "$HOME/Desktop/Logs.desktop"
xfdesktop --reload 2>/dev/null || true
```
