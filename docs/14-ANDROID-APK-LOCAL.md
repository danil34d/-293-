# Android APK для локальной сети

## Решение

Для локального разворота проекта на Android нужен не PWA, а отдельный APK-оболочка.

Рекомендуемый вариант:

- Android-приложение с `WebView`
- стартовый адрес: `http://192.168.1.36:3000/login`
- режим использования: только внутри локальной сети

## Почему именно WebView APK

### Подходит под текущую инфраструктуру

Сервер уже работает в локальной сети:

- `http://192.168.1.36:3000/login`
- `http://192.168.1.36:3000/wallboard`

Для Android это значит:

- приложение можно сделать тонкой оболочкой
- серверная логика остаётся на Linux
- Android нужен только как клиент

### Почему не PWA

PWA добавлен в проект и полезен как задел на будущее, но для чистой локалки этого недостаточно:

- локальный HTTP ограничивает поведение service worker
- UX для массового разворота хуже, чем у APK
- сотруднику проще поставить готовый APK, чем объяснять установку из браузера

### Почему не Trusted Web Activity

TWA хорош для HTTPS и нормального публичного домена.
Для локального адреса `192.168.1.36` это не лучший путь.

## Что должен уметь Android APK

- открывать локальный URL в `WebView`
- не показывать лишний браузерный интерфейс
- иметь нормальное имя и иконку
- при недоступности сервера показывать понятное сообщение
- по возможности иметь экран "Сервер недоступен"

## Базовая архитектура Android-клиента

- `MainActivity`
- `WebView`
- разрешение `INTERNET`
- опционально:
  - проверка доступности `192.168.1.36:3000`
  - fallback screen
  - экран настроек адреса сервера

## Что важно для стабильности

- у Linux должен оставаться фиксированный IP `192.168.1.36`
- Android-устройства должны быть в той же Wi-Fi сети
- сервер Linux должен быть включён

## Ограничения текущей рабочей машины

На текущем Windows-ПК не установлен `Java`, поэтому здесь пока не запускалась сборка APK:

- `java -version` -> команда не найдена

Это значит:

- концепцию зафиксировали
- PWA и HTTPS-контур уже подготовлены
- следующий практический этап для APK: установка JDK/Android SDK и создание Android-проекта

## Следующий шаг

Когда вернёмся к теме, делать так:

1. Установить JDK.
2. Установить Android Studio / Android SDK.
3. Создать отдельный Android-проект-оболочку.
4. Подключить `WebView` к `http://192.168.1.36:3000/login`.
5. Собрать `debug APK`.
6. Проверить установку и работу на Android в локальной Wi-Fi сети.
