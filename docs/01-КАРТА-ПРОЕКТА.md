# Карта проекта

## Структура
- `src/app` - страницы и API роуты Next.js.
- `src/components` - UI и прикладные React-компоненты.
- `src/lib` - серверная бизнес-логика, загрузка данных, AI, утилиты.
- `src/types` - доменные типы проекта.
- `backend-go` - отдельный Go backend (Fiber).
- `data` - рабочие данные проекта (JSON + SQLite).
- `scripts` - служебные скрипты (OCR, проверки, совместимые entrypoint-обертки).
- `telegram-bot` - отдельная папка Telegram worker (`worker.mjs`, `README`, `ЖУРНАЛ-РАБОТ`, `.env.local`).
- `доки` - эксплуатационная документация.

## Ключевые модули
- Auth: `src/contexts/AuthContext.tsx`, `src/app/api/auth/*`
- Мойки/балансы/химия: `src/app/api/wash-events/*`
- Расходы/склад: `src/app/api/expenses/*`, `src/app/api/inventory/*`
- Смены/планирование: `src/app/schedule/*`, `src/app/schedule/planning/*`, `src/app/employee/schedule/*`, API: `src/app/api/shifts/*`, `src/app/api/schedule-plans/*`, `src/app/api/employee-day-statuses/*`, `src/app/api/shift-*-requests/*` (подробно: `доки/08-ГРАФИК-СМЕН-И-ПЛАНИРОВАНИЕ.md`)
- Погода/паттерны для планирования: API `src/app/api/weather/forecast/route.ts`, `src/app/api/pattern-journal/month/route.ts`, сервис `src/services/weather-forecast-service.ts` (подробно: `доки/09-ПОГОДА-И-ПАТТЕРНЫ.md`)
- AI assistant: `src/app/api/ai-assistant/*`, `src/lib/ai/*`
- OCR номера: `src/app/api/recognize-plate/route.ts`, `scripts/plate_reader.py`
- Telegram bot worker: `telegram-bot/worker.mjs` (+ совместимый entrypoint `scripts/telegram-worker.mjs`), `src/app/api/telegram/internal/*`, `src/services/*`
- Формы с валидацией: локальный резолвер `src/lib/zod-resolver.ts`

## Go backend
- Entry point: `backend-go/cmd/server/main.go`
- Health: `/health`
- Работает на порту `8080`.
- Использует те же данные из `data/`.

## Режимы работы API
- `USE_GO_BACKEND=false`: API обслуживает Next.
- `USE_GO_BACKEND=true`: большинство `/api/*` проксируется на Go backend.

## ENV конфигурация
- `.env.local` (корень): общие настройки приложения (backend и AI).
- `telegram-bot/.env.local`: отдельные настройки Telegram-бота (токен, секрет, привязки сотрудников, интервалы).

## Данные
- `data/*` - основное файловое хранилище сущностей.
- `data/ai-assistant.db` - SQLite база для AI чатов и фоновых анализов.
- `data/_meta/schema-version.json` - версия файловой схемы (`json-v2`).
- `data/_meta/migration-log-*.json` - отчеты миграций.
- Подробная карта взаимодействий: `доки/06-ЖУРНАЛ-БД-ВЗАИМОДЕЙСТВИЯ.md`.

## Миграция JSON v2
- Оркестратор: `scripts/migrations/json-v2/index.mjs`.
- Режимы:
  - `dry-run` - только диагностика;
  - `apply` - с бэкапом `data-backups/YYYYMMDD-HHMMSS/`.
- Команды:
  - `npm run migrate:json-v2:dry-run`
  - `npm run migrate:json-v2:apply`
  - `npm run migrate:json-v2:apply:fix-balances`

## OCR (распознавание номера)
- Runtime Python определяется автоматически (`python`, `py -3`, `python3`).
- Временные файлы создаются в `%TEMP%\carwash-plate-temp` (Windows).
- По умолчанию temp-файлы удаляются после обработки.
- Флаг отладки: `KEEP_PLATE_TEMP_FILES=1`.

## Запуск/остановка на Windows
- Запуск: `START.bat` / `START.ps1`
- Остановка: `STOP.bat` / `STOP.ps1`
- Порты: frontend `3000`, backend `8080`
- По умолчанию старт в режиме `USE_GO_BACKEND=false` (Next API), если в `.env.local` не указано иное.
