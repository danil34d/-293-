# План запуска проекта

## Что запускается
- Frontend: Next.js (предпочтительно `http://localhost:3000`, при занятом порту автоматический переход на `http://localhost:3001..3005`)
- Backend: Go Fiber (предпочтительно `http://localhost:8080`, при занятом порту автоматический переход на `http://localhost:8081..8085`) только если `USE_GO_BACKEND=true`
- Данные: JSON в `data/` и SQLite `data/ai-assistant.db`

## Системные требования
- Windows x64
- Node.js 20+
- npm
- Go 1.23+ (только для режима `USE_GO_BACKEND=true`)
- Python 3 (для распознавания номеров)

## Рекомендуемый запуск на Windows
1. Открыть `cmd` или PowerShell в корне проекта.
2. Запустить:
   - `START.bat` или
   - `./START.ps1`
3. Проверить:
   - адрес frontend из вывода `START.ps1` (по умолчанию `http://localhost:3000`, fallback `3001..3005`)
   - адрес backend из вывода `START.ps1` (только при `USE_GO_BACKEND=true`)

## Логин в систему
- `admin / admin`
- Источник: `data/employees/emp_manager_admin.json`

## Остановка
- `STOP.bat` или `./STOP.ps1`

## Переменные окружения
- Общие переменные проекта хранятся в корневом `.env.local`:
  - `USE_GO_BACKEND=true|false` - включить/выключить прокси API на Go backend;
  - `GO_BACKEND_URL=http://127.0.0.1:8080`;
  - `GLM_API_KEY=...` - для AI функционала;
  - `NEXT_PUBLIC_GEMINI_API_KEY=...` - опционально для старого AI-сценария;
  - `TELEGRAM_BOT_SECRET=...` - должен совпадать с `telegram-bot/.env.local` для internal API.
- Переменные Telegram-бота хранятся отдельно в `telegram-bot/.env.local`:
  - `TELEGRAM_BOT_ENABLED`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_SECRET`,
  - `TELEGRAM_EMPLOYEE_CHAT_MAP_JSON`, `TELEGRAM_ADMIN_CHAT_IDS`,
  - `TELEGRAM_SCAN_INTERVAL_SEC`, `TELEGRAM_API_TIMEOUT_SEC`, `TELEGRAM_TIMEZONE`, `TELEGRAM_APP_BASE_URL`.

## Проверка после старта
- `/login` открывается
- `/employee/workstation` открывается после входа
- `/api/recognize-plate` отвечает JSON
- `/health` у Go backend отвечает `status: ok` (только при `USE_GO_BACKEND=true`)

## Важные заметки для Windows
- `START.ps1` читает `USE_GO_BACKEND` и `GO_BACKEND_URL` из `.env.local`.
- `START.ps1` перед новым запуском останавливает предыдущие процессы этого проекта из текущей рабочей папки, чтобы не плодить несколько копий Next.js и Telegram worker.
- `START.ps1` не убивает чужие сервисы на `3000/8080`: если порт занят внешним процессом, выбирается следующий свободный порт из диапазонов `3001..3005` и `8081..8085`.
- Если `USE_GO_BACKEND=false`, проект работает на локальных Next API и Go не требуется.
- Для OCR API Python подбирается автоматически: `python`, `py -3`, `python3`.
- Временные файлы OCR пишутся в системный temp-каталог (`%TEMP%\carwash-plate-temp`) и автоматически удаляются.
- Для отладки можно оставить temp-файлы: `KEEP_PLATE_TEMP_FILES=1`.

## Безопасная пересборка
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\rebuild-safe.ps1
```

Что делает:
- `STOP.ps1`
- `scripts/cleanup-safe.ps1`
- установка зависимостей
- `npm run typecheck`
- `npm run build`
- `TELEGRAM_BOT_ENABLED=false npm run bot:telegram`
- опционально `go build ./...` если Go установлен

## Частые проблемы

### Порт занят
- Если `3000` или `8080` занят чужим приложением, `START.ps1` сам выберет следующий свободный порт и напишет фактический адрес запуска.
- Если все порты в диапазоне заняты, освободи один из портов `3000..3005` (и `8080..8085` для Go backend), затем повтори запуск.

### Не работает OCR
- Проверить Python:
  - `python --version`
- Установить зависимости OCR:
  - `pip install -r scripts/plate_requirements.txt`

### Нет AI ответов
- Проверить наличие `GLM_API_KEY`.
