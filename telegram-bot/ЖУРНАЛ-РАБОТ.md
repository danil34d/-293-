## 2026-02-15 (чатовый мастер `/wash`, этап 1)
- Реализован новый основной сценарий регистрации мойки в чате: `/wash`.
- Добавлена кнопка меню `🚗 Оформить мойку` (`cmd:wash`).
- Внедрены шаги мастера:
  - команда исполнителей;
  - ввод номера (текст/фото OCR);
  - выбор оплаты;
  - выбор агрегатора/контрагента;
  - выбор услуг (поиск, пагинация, повтор прошлой мойки, произвольные услуги);
  - комментарий и подтверждение.
- Добавлены internal API для `/wash`:
  - `GET /api/telegram/internal/wash/bootstrap`
  - `POST /api/telegram/internal/wash/detect-vehicle`
  - `GET /api/telegram/internal/wash/services`
  - `POST /api/telegram/internal/wash/submit`
  - `POST /api/telegram/internal/recognize-plate`
- OCR вынесен в общий сервис `src/services/plate-recognition-service.ts` и используется:
  - в `POST /api/recognize-plate`;
  - в Telegram internal OCR endpoint.
- Логика сохранения мойки вынесена в общий сервис `src/services/wash-event-create-service.ts`:
  - `POST /api/wash-events` и Telegram submit используют один код и одинаковые побочные эффекты.
- Идемпотентность submit усилена:
  - повторный submit по одному `draftId` возвращает ту же запись;
  - добавлен детерминированный `washEventId` для Telegram (`we_tg_<hash>`).
- Смоук-проверки:
  - `npm run typecheck` -> OK;
  - `npm run build` -> OK;
  - `TELEGRAM_BOT_ENABLED=false npm run bot:telegram` -> graceful exit;
  - `/api/telegram/internal/wash/*` -> OK (bootstrap/detect/services/submit);
  - параллельный submit одного draft -> один `washEventId` (без дублей).

## 2026-02-15 (структура меню + фиксы мастера даты)
- Главное меню переработано в более структурированный вид:
  - `🚿 Рабочая станция`
  - `🗓 Сегодня`, `📅 Неделя`, `🧾 Месяц`
  - `📨 Заявки`, `➕ Запрос смены`
  - `💰 Финансы`, `🔄 Обновить`
  - `❓ Помощь`
- В карточку меню добавлена сводка по сотруднику:
  - смены на сегодня,
  - счетчики заявок,
  - баланс за текущий месяц,
  - время обновления.
- Исправлена валидация даты в мастере запроса смены:
  - убран timezone-баг для `YYYY-MM-DD` (например `2026-02-15` теперь валиден),
  - добавлена поддержка `DD.MM.YYYY` (например `15.02.2026`).
- Добавлены callback-действия `cmd:menu` и `cmd:help`.
- Добавлен fallback для запуска станции в локальном режиме:
  - при `http://localhost`/`http://127.0.0.1` бот отправляет ссылку текстом (без URL-кнопки), чтобы не падать на ошибке Telegram `Wrong HTTP URL`.

## 2026-02-14 (WebApp + паритет workstation)

  - новая команда `/workstation`
  - новая кнопка меню `🚿 Рабочая станция` (`cmd:workstation`)
  - бот отправляет `web_app` кнопку `🚿 Открыть рабочую станцию`.
- Добавлен TTL WebApp-сессии:
  - `TELEGRAM_WEBAPP_SESSION_TTL_SEC` (по умолчанию 120 сек).
- Создан подробный журнал логики меню и переходов:
  - `telegram-bot/ЛОГИКА-БОТА-И-МЕНЮ.md`.
- Выполнен смоук после релиза:
  - `npm run typecheck` -> OK;
  - `npm run build` -> OK;
  - `TELEGRAM_BOT_ENABLED=false npm run bot:telegram` -> graceful exit;
  - `POST /api/telegram/internal/webapp-session/create` -> OK;
  - `GET /api/telegram/webapp-login?token=...`:
    - первый вход -> redirect на `/employee/workstation` + cookie;
